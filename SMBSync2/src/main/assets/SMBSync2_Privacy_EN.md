# Your data

SMBsync+ does not send usage statistics, diagnostics, or account details to its developer. It has no app account and does not include advertising or analytics services.

Folder pairs, connection details, settings, and sync history are stored on this device. Connection passwords are encrypted when saved. Files are transferred only between locations selected in a folder pair, including SMB servers you configure. Sync logs can contain file paths and device details; you can review or share them from the app.

Checking for updates contacts GitHub when you select **Check for updates**. Downloading an update also uses GitHub. The app does not check for updates in the background.

You control folder pairs, schedules, connections, and stored history in the app. You can export settings or share logs yourself. Files copied to another location remain there until you remove them from that location.
